# 录屏与压制参数（B站）

## OBS 设置

| 项 | 值 |
|---|---|
| 采集 | 窗口采集 FrameLab（或显示器采集，仅当需要演示桌面拖拽时） |
| 输出分辨率 | 1920×1080 |
| 帧率 | 60 fps |
| 录制编码 | x264（CQP 18）或 NVENC（RTX 5060 Ti，CQP 17，CPU 占用更低） |
| 录制格式 | MKV（崩溃不丢片，录完转封装 MP4） |
| 音频 | 无口播则直接静音轨（成片配 BGM）；有口播用 48kHz |

## 压制（发布前必做）

```bash
ffmpeg -i raw.mkv -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k bilibili-final.mp4
```

NVENC 版（更快）：把 `-c:v libx264 -crf 18 -preset slow` 替换为 `-c:v h264_nvenc -cq 19`。

## 上传前自查清单

- [ ] 分辨率 1920×1080、60fps、总长 60-90s
- [ ] 前 5 秒见产品成品（无片头动画）
- [ ] BGM 音量不压字幕/口播；音轨清晰无爆音
- [ ] 上传后用 B站二压成片自己完整看一遍：文字是否糊（尤其 EXIF 参数行）、拖拽是否卡顿
- [ ] 简介链接可点、置顶评论已发
