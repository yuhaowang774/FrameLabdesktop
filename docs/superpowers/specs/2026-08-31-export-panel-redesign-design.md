# 导出界面精装改造设计（Export Panel Redesign）

> 日期：2026-08-31
> 状态：设计已获用户批准（方案 A：单页精装改造）
> 范围：`ExportPanel.vue` 主体 + `core/exporter.ts` 尺寸函数提取 + Tauri `reveal_path` command + `platform/fs.ts` 包装 + 单测

---

## 一、背景与目标

导出模块（图库/编辑/导出三段式工作流的第三段）功能完整，但存在四个体验短板（用户确认全选）：

1. 视觉风格平淡：卡片无层次、按钮不突出、缩略图条简陋
2. 缺输出信息预估：看不到导出分辨率/预估体积，超采样靠猜
3. 导出进度反馈弱：批量导出只靠顶部全局细进度条，无页内反馈
4. 预览弹窗简陋：只有保存按钮，无分辨率/体积信息、不能放大查看、桌面端无「打开所在文件夹」

**风格决策**：延续全应用方正极简语言（细边框、直角、灰度、冷灰蓝），仅做局部强化；不做圆角/阴影的现代卡片风。

## 二、布局与视觉

### 2.1 分组结构
- 每张卡片改为「分组头 + 分组体」：分组头 = 12×12 线性图标（复用 `Icon.vue`）+ 标题 + 右侧辅助说明文字；分组体上下留白加大
- 卡片间距统一 12px；页面最大宽度约束（约 960px 居中），避免超宽屏拉散

### 2.2 控件
- 画质滑块：裸 `<input type=range>` → 项目现有 `RangeSlider` 组件（统一控件语言）
- 分段选中态（seg）对比强化：选中态背景用强调色、文字用高对比色，未选中保持灰
- 「格式」与「超采样」合并为一个「输出」分组行组；批量回填/文本映射归入「批量选项」分组

### 2.3 照片选择
- 缩略图从 96px 单行横向滚动改为网格：`repeat(auto-fill, minmax(112px, 1fr))`，容器 max-height 约 260px 内部滚动
- 保留现有多选交互（点击选择 / Ctrl+点击切换 / Shift+点击范围）；选中态与激活态样式沿用现有 token

### 2.4 任务卡吸底
- 「导出任务」卡片改为 `position: sticky; bottom: 0`（页面滚动容器内常驻底部），背景加面板底色与上边框，任何滚动位置可直接操作
- 内容三段：左侧预估信息（见三）、中部进度/汇总（见四）、右侧操作按钮
- 「导出当前照片」为主按钮（强调色、加大高度）；「批量导出」为次级按钮；批量进行中主按钮替换为「取消」

### 2.5 批量同步降级
- 「批量同步」卡收窄为次级卡片，置于输出设置卡之后，分组头注明"保存当前配置为模板"

## 三、输出预估

### 3.1 尺寸函数提取（同源公式）
- 从 `core/exporter.ts` 的 `exportFrame` 内部提取画布尺寸计算为导出纯函数：

```ts
export function estimateExportSize(
  srcW: number, srcH: number,
  config: FrameConfig, scale: number,
): { w: number; h: number }
```

- `exportFrame` 改为调用该函数，导出与预估共用同一公式，杜绝两套口径
- 预估不含体积的精确性承诺：JPG 体积按 `像素数 × 系数（quality 相关）` 粗估，界面标注「约」

### 3.2 展示
- 任务卡左侧实时显示：`输出 ≈ 8064 × 6048 px`；JPG 追加 `≈ 8.5 MB`
- 联动刷新：当前照片切换、超采样/格式/画质/边框相关参数变化时重算
- 源图尺寸获取：`ExportPanel` 内对当前激活照片懒加载 `Image` 读 `naturalWidth/Height`，缓存到模块级 Map（key = item.id）；读取失败显示 `—`，不阻塞导出

## 四、页内进度与取消

### 4.1 进度区（任务卡中部）
- 空闲：不显示
- 进行中：细进度条 + 文本 `3/12 · IMG_1234.JPG`（沿用 `setTaskLabel` 的逐张标签数据）
- 完成：`✓ 成功 12 · 失败 0`；失败 >0 时列出失败文件名（最多 5 行，超出折叠为「等 N 张」）
- 手动取消：`已导出 5/12（已取消）`

### 4.2 取消
- 模块级 `cancelRequested` 标志位；点击「取消」后**当前张渲染完成后**停止循环（不中断进行中的渲染）
- 单张导出不提供取消（耗时可控）

### 4.3 反馈通道收敛
- 批量导出失败不再 `window.alert` 打断，统一进页内汇总
- 顶部全局任务条保留不动（跨模块可见），页内进度为导出页增强视图，两者并行不冲突
- 批量同步保存成功提示保留 `window.alert`（低频操作，可接受）

## 五、预览弹窗增强

### 5.1 信息
- 底栏：文件名（省略号）+ 分辨率 + 实际体积（`blob.size` 格式化 B/KB/MB）
  - 分辨率口径唯一：预览弹出时用 `Image` 加载 blob 实测 `naturalWidth/Height`（预览图即导出成品，实测最准），不用预估口径

### 5.2 查看
- 点击图片切换缩放模式：适应窗口（默认）/ 1:1 原大；1:1 模式容器 `overflow: auto` 可拖动滚动
- 关闭按钮与遮罩点击关闭沿用现状

### 5.3 保存与定位
- 「保存图片」主按钮：桌面端系统对话框写盘（`saveBlobAs`）、网页端浏览器下载（现状保留）
- 保存成功后底栏追加「已保存 ✓」状态；**桌面端**追加「打开所在文件夹」按钮：
  - 新增 Rust command `reveal_path(path: String)`：Windows `explorer /select,"<path>"` 定位文件（失败静默返回错误串）
  - `platform/fs.ts` 新增 `revealInExplorer(path)` 包装（内部动态 import invoke，延续惰性加载约定）
  - 网页端不显示该按钮
- 批量导出最后一张预览时同样适用（其文件已落盘）

## 六、错误处理与边界

- 源图尺寸读取失败 → 预估显示 `—`；导出本身仍按原图尝试（失败走页内汇总）
- 预览 objectURL：替换/关闭时 revoke（沿用现有逻辑）
- 批量过程中新增照片/删除照片：导出列表在启动时快照，不受过程中图库变化影响
- 取消与异常并存：异常终止同样进汇总（`失败原因` 取 Error.message）

## 七、测试

- `estimateExportSize`：与 `exportFrame` 公式同源后的参数化断言（默认背景 / none 模式 / 多倍超采样 / 极端 padding）
- `parseRules`：正常行 / 空行 / 缺替换 / 值中含 `=>`（现有函数补测）

### 7.2 手动验收清单

- 桌面端：批量 3 张 → 进度逐张刷新 → 中途取消 → 汇总正确
- 网页端：批量 → 浏览器逐张下载 → 无「打开所在文件夹」按钮
- 预览 1:1 切换拖动查看；JPG/PNG 画质/超采样变化时预估联动
