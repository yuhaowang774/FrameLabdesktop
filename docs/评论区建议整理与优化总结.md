# 十二、其它零散 / 同类工具（Semi-Utils、Copicseal）特有

**Semi-Utils（命令行工具）硬伤（可作壹印差异化优势参考）**：
- 解压后无 input/output 文件夹需手动建；`ModuleNotFoundError: No module named 'tqdm'` 缺依赖；中文/外语路径报错读不到 EXIF
- 格式支持极窄：raw/nef/rwl/png/dng/heif 直接报"只支持 jpg"
- 副厂/手动镜头只标型号不显示 Logo；等效焦距不换算
- Mac 运行报错/终端无反应；无 exe，pycharm 跑完参数全空白；win11 双击打开是压缩包预览
- **死循环 bug（已确认真实成因）**：Mac 垃圾桶未清空、无 EXIF 图片、0字节/损坏图、交互输入 `y` 均会触发死循环（传什么图都循环），需回退老版本；作者已在 build1517 修复
- 结论：命令行/开源方案部署门槛高，**壹印"开箱即用 GUI + 中文路径兼容"是核心卖点**

**Copicseal（开源 GUI）痛点**：导出没反应、配置不保存、个人 logo 待补、字体单一、超分崩溃、GitHub 下载慢。

**开源 / 插件 / 本地版**（加分项）：Semi-Utils、Copicseal 均证明社区价值；用户呼吁 PS/LR 插件、开源、本地离线版。

# 总结：需要优化的核心方向（按优先级）

## 🔴 P0 —— 必须尽快修的「硬伤」
1. **导出画质压缩严重**（跨所有版本共识）：体积/分辨率/色彩被压。需原画质/质量可选/无损输出；高像素机型放开 PIL 像素上限、保色深、sRGB 避免偏色、模糊断层加微量噪点。
2. **安装/启动/闪退**：Win11 24H2 打不开、双击无反应、权限/安装目录（"装C盘""选全用户"）、导出强退。需免安装绿色版 + 崩溃日志自动收集 + 旧版升级兼容。
3. **大图闪退 & 卡加载**：20M+/RAW/LR 转出 jpg 导入即闪退；启动卡加载中。
4. **编辑文本/参数卡死**："打一字卡 5s"，UI 主线程/输入响应需优化。
5. **导出命名 bug**：`xxx.jpg-1` 破坏后缀、日期光标错乱。
6. **结果实时预览缺失**（极高频）：用户反复导出试错，需加半实时/结果预览。

## 🟠 P1 —— 高频功能缺失
7. **真正的批量 + 模板保存应用**（被提最多）：自定义模板（边框/logo/文字/颜色）保存并一键应用到全部照片；无 EXIF 照片分流；参数替换映射（批处理不同镜头）。
8. **自定义 logo 跨平台稳定**：Mac 普遍报错、Win 需管理员；支持删除/缩放/PNG；修正松下=Lumix、补苹果/影石/哈苏等品牌库；新机型库及时更新（Z50二代等）；logo 颜色可改。
9. **EXIF 准确性**：长曝光快门 >1s 显示 1/0s、焦段识别错误（读错原始值）、等效焦距换算、镜头 logo 缺失只标焦段、修图/裁切/文件夹空格导致 EXIF 丢失、HDR 丢失、品牌名可手动改、时区错误只显示秒、日期只显示到日。
10. **高斯模糊/背景模糊模板增强**：模糊程度/圆角数值、输出比例、日期/参数开关、去参数、统一文字排列、超分崩溃修复、色彩偏暗修正。
11. **配置持久化**：保存用户配置，避免每次恢复默认。

## 🟡 P2 —— 体验与扩展
12. **多格式支持**：HEIF/HEIC、PNG、TIF、RAW（ARW/CR/NEF/CR2/DNG）、JPEG XL、HDR 保留。
13. **全平台覆盖**：Mac/iOS 安装包、Android、鸿蒙、Linux、TV、小程序；离线本地版。
14. **界面交互**：字体/大小/颜色选择、文字吸附+靠右同行、边距/四边等宽/留白可调、滚动与滑块冲突、统一各端导出/更新按钮、窗口控件适配、单图放大预览。
15. **方向/比例/边框**：竖版模板、旋转信息正确处理、竖图文字不重叠、按厚度统一输出比例、竖图转横（背景模糊）、多竖图拼横排。
16. **附加信息项**：地址栏（经纬度→省+市）、签名、镜头型号、公司名/联系方式、立体阴影、纯白底/纯边框无参数轻量选项、叠加式（侵入画面）水印、简单模板降低信息过载感。
17. **基础设施**：官网稳定性与下载加速、网盘/离线包/GitHub 镜像多通道兜底。
