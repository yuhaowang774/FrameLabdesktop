## 二、本次实地观察到的代表性样式（按学习价值排序）

1. **大师水印·四栏参数表**（白海报款 / 1:1 款 / Leica 红点款 / Hasseblad 衬线款）：
   白底海报 + 居中照片 + 顶部品牌字标 + 底部 `CREATED BY … / The Precious Moment`
   + **四栏参数表**（数值粗大在上、单位细小在下，栏间细线分隔：`16 mm｜2.8 f｜3200 s｜200 ISO`）。
   对应 `docs/相框风格分析与模板更新.md` 的「画廊签名款」，代码注释中标注"超出 INFO 布局引擎能力"。
2. **右缘竖排签名条**：照片右缘一条半透明渐变竖带 + 竖排花体签名 + 竖排参数
   （`14 mm  f  1/4000s`）。
3. **旅行票根**：纯色底 + 白色票据卡（内嵌照片 + `THIS STATION / 城市名 / 日期` +
   条形码 + 撕线缺口），横版/竖版/宽条三变体。
4. **色卡边框**：照片 + 底部（或右缘竖排）5 枚色块 + hex 色号标注。
5. **杂志封面款**：全幅照片压大标题（衬线 MASTER PHOTOGRAPHY）+ 顶部报头行
   （DESIGN BY / 日期 / NUMBER 1）+ 底部宣传语；展览款 = 图片 + 标题 + 多行介绍段落 +
   大字标语（LEICA MASTERSHOT）。
6. **运动边框**：全幅照片 + 运动遥测数据叠加（速度/焦距/快门，深色渐变压底）。
7. **相机品牌联名白条**：底部白带 `DJI MAVIC 4 PRO / HASSELBLAD` 等联名排版、
   GPS 坐标款（`2026.08.19 / 23°51'3"N 113°9'28"E`）。

## 三、落地路线图

### A. 纯参数可落地（无需引擎改动）——已落地
2026-09-14 已按官网展示样式新增 9 套（多彩色卡 ×5、旅行杂志 ×2、画册署名 ×2）。

### B. 需要小引擎扩展（✅ 已于 2026-09-14 全部落地）
1. ✅ **四栏参数表布局** `infoLayout: 'poster'`：`computePosterLayout` + posterParams
   （焦距 mm/光圈 f/快门 s/ISO，取自 exifRaw，缺失栏跳过）+ 三端渲染（导出/预览/缩略图）
   + 模板「大师水印·白海报 / 方幅」——画廊签名款正式落地。
2. ✅ **色卡 hex 标注**：`paletteHex` 字段（magazine 布局色块下方一行 hex 小字），
   三端同源；「色卡·明黄/抹茶」已开启。
3. ✅ **票根近似**：白卡（bgColor）+ 彩色外圈（borderColor）+ 照片 scale 内缩 +
   城市名用水印文字承载（水印文字可改）；撕线/条形码/缺口造型仍缺（远期）。
   模板「旅行票根·横版 / 竖版」。
4. ✅ **GPS 坐标**：exifr pick 增加 latitude/longitude，`exifRaw` 增补字段，
   `formatGps` 度分秒格式化 + `{gps}` 占位符进入 infoLayer EXIF 元素模板
   （用户可在自由元素里拼 `日期 · {gps}` 排版）。builtin 坐标款模板已于 C 节
   随自由元素边缘锚定能力补齐（「GPS坐标·旅行印迹」，{date}/{gps}/{model} 三行）。

### C. 需要较大投入（远期）——2026-09-14 执行四项，拼图延期
1. ✅ **日历边框**（月历网格 + 农历换算）：新增 `infoLayout: 'calendar'` 布局——
   年月标题行（衬线年份 + 月名）+ 分隔线 + 星期表头 + 6 行公历/农历网格（`core/lunar.ts`
   位表算法换算，初一显示农历月名），拍摄日期用强调色圆点标记（`calendarAccent`，
   浅底珊瑚红/深底暖橙，可自定义）。三端渲染 + 「月历·白纸手账 / 暗夜桌历」模板，
   新增模板分组「日历边框」。
2. ✅ **运动边框**（运动数据导入/解析）：`core/gpx.ts` 解析 GPX（Haversine 距离 /
   时长 / 均速 / 峰值速度 / 海拔爬升 / 轨迹归一化 ≤500 点等比缩放）写入 `config.telemetry`
   （照片自身数据，不进模板、批量应用保留）；新增 `infoLayout: 'sport'` 布局——
   轨迹缩略卡（半透明卡 + 强调色折线 + 起/终点圆点）+ 四栏数值/单位遥测表
   （距离 km / 时长 min / 均速 km/h / 爬升 m，缺失字段自动跳过）。INFO 面板 GPX
   导入入口 + 「运动·暗调遥测 / 白底数据表」模板，新增分组「运动边框」。
3. ✅ **设备样机（手机壳）**：`core/deviceMockup.ts` 绘制设备轮廓——边框环沿照片边缘
   内收（厚度 1.6% 比例，与照片圆角同心）+ 顶部灵动岛胶囊，直接画进照片画布
   （预览 MainPhoto 与导出 exporter 同一函数，缩略图 SVG 同比例复刻）。
   `config.deviceMockup`：`phone-dark`（深空灰）/ `phone-light`（银色），边框面板
   新增「设备样机」选择器 + 「设备样机·深空灰 / 银色」模板与分组。
   相机机身样机需要更高精度的外观资产，继续留在远期。
4. ✅ **杂志封面款**（照片压大标题 + 报头行）：信息层自由元素新增**边缘锚定能力**
   （`anchorX: 'left'|'center'|'right'`、`anchorY: 'top'|'center'|'bottom'`，
   元素原点 = 锚点边 + 偏移，画布尺寸变化时精确贴边；align=left/right 语义改为
   「原点 = 文本盒左/右缘」，center 不变）+ 文字元素 `shadow` 投影 + EXIF 模板
   `{date}` 字段（B4 遗留的坐标款同时解锁）。「杂志封面·刊头款 / 展览款」
   归入「杂志编辑」，「GPS坐标·旅行印迹」归入「联名卡」。
5. ⏸ **拼图（宫格布局）——延期，理由如下**：FrameLab 的画布几何（`computeExportMetrics`）、
   照片层（单 `photoSrc` + 旋转/裁剪变换）、编辑历史与图库缓存均为单照片架构；
   宫格拼图需要「多照片图层 + 每图独立裁剪变换 + 宫格模板几何系统 + 缩略图/导出
   全链路改造」，属于数据模型级重构而非布局扩展，且与现有「单照片精修」产品定位
   有张力。建议作为独立立项（多照片合成模式）规划，不混入 FrameElf 样式跟随批次。

**配套引擎变化**：内置模板 53 → 62 套，模板分组 11 → 14 组；`computeCalendarLayout` /
`computeSportLayout` 与 `lunar.ts` / `gpx.ts` / `deviceMockup.ts` 均带独立测试
（农历表以 2020–2029 春节 + 传统节日锚点校验）。

## 四、结论

FrameElf 的差异化主要在：**布局类引擎能力**（四栏参数、票据、日历、拼图）而非配色/
字体类皮肤。FrameLab 已用参数组合覆盖其约六成样式观感。B 节（四栏参数表/色卡 hex/
票根近似/GPS 坐标）与 C 节四项（日历/运动/手机样机/杂志封面）已于 2026-09-14 全部落地，
仅剩拼图（需多照片架构重构，独立立项）与相机机身样机（需外观资产）留在远期。
